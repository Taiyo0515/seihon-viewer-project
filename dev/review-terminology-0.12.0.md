# 0.12.0 用語の確認記録

2026-10-30。文言は同義語の一律置換ではなく、利用者が行う操作に合わせて整理した。

## 使い分け

- 出力: 機能、生成結果、その条件の説明。「製本用PDF出力」「出力品質」「付属の出力」「出力しない」等は維持する。
- 作成: PDFや画像の内容を組み立てる段階。
- 保存: ファイルを保存する操作・処理結果、拡張機能内の設定やデータの記録。
- 印刷: 印刷画面に進む操作と紙への印刷。
- コピー: クリップボードへの受け渡し。補助プログラムがないため一時ファイルへ保存する場合は、その両方を説明する。
- ダウンロード: サイト・Chromeの通信処理、元リンク、Chromeのダウンロードフォルダー等の名称に残す。
