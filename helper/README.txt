製本ビューア 補助プログラム(ファイルをクリップボードに入れる)
====================================================================

ページ収集の「PDF としてコピー」「画像としてコピー」などで、貼り付けたときに
「ファイル」として貼り付くようにするための、小さな補助プログラムです。

ブラウザの決まりで、拡張機能だけではファイルをクリップボードに入れられません
(入れられるのは文字と、画像1枚だけ)。補助プログラムを入れると、製本ビューアから
受け取った PDF・画像を見えない一時フォルダ(Windows は %TEMP%\seihon-viewer-copy)に置いて、
エクスプローラー(Finder)の「コピー」と同じようにクリップボードに入れます。
コピーは使い捨てで、次にコピーすると前のコピーのファイルは消えます(0.4.1 から。
「ダウンロード」フォルダには何も残りません)。
フォルダやチャット欄などに Ctrl+V で貼り付けられます。
Chrome のダウンロードを通さないので、Chrome の「保存する前に各ファイルの保存場所を
確認する」がオンでも、聞かれずに裏で保存します。

補助プログラムは、製本ビューアから受け取ったファイルを保存してクリップボードに入れる
(と、頼まれたときにそのフォルダを開く)だけで、ネットワークは使いません。
製本ビューア以外の拡張機能からは呼べません。
入れなくても製本ビューアは使えます(そのときは、Chrome のダウンロードで保存して、
保存したファイルの場所を文字でクリップボードに入れます)。
補助プログラムは拡張機能のフォルダの中にあるので、製本ビューアを新しい版に置き換えると、
補助プログラムも新しい版になります(入れ直しは要りません)。

--------------------------------------------------------------------
入れ方
--------------------------------------------------------------------
1. 製本ビューアの「詳細設定」→「コピー・画像」→「補助プログラム」で、
   「補助プログラムを使えるようにする…」を押し、Chrome の確認で「許可」を押します。

2. 使っているパソコンのものを実行します。
   Windows : windows フォルダの install.bat をダブルクリック
             (PowerShell を使います。Windows 10 / 11 に最初から入っています)
   Mac     : mac フォルダの install.command を右クリック →「開く」
             (最初に「開発元を確認できない」と出たら「開く」を押します)
   Linux   : 端末で  sh helper/linux/install.sh
             (xclip または wl-clipboard が必要です。例: sudo apt install xclip)

3. 「詳細設定」の「もう一度確かめる」を押し、「使えます」と出れば準備完了です。

製本ビューアのフォルダを移動したときは、もう一度 2 を行ってください。

--------------------------------------------------------------------
やめ方
--------------------------------------------------------------------
Windows : windows フォルダの uninstall.bat をダブルクリック
Mac     : mac フォルダの uninstall.command を右クリック →「開く」
Linux   : sh helper/linux/uninstall.sh
「詳細設定」の「使うのをやめる」で、Chrome の権限も外せます。

--------------------------------------------------------------------
しくみ(詳しい方へ)
--------------------------------------------------------------------
Chrome の「ネイティブ メッセージング」を使います。install は、Chrome に
補助プログラムの場所を知らせる小さな設定ファイル(com.seihon_viewer.clipboard.json)を
登録するだけです(Windows はこのユーザーのレジストリ、Mac・Linux はこのユーザーの
Chrome の設定フォルダ)。
  Windows : seihon-clipboard.ps1(PowerShell。.NET の Clipboard.SetFileDropList)
  Mac     : seihon-clipboard.js(osascript の JavaScript。NSPasteboard)
  Linux   : seihon-clipboard.py(Python 3。xclip / wl-copy で text/uri-list)
ファイルのデータは、1MB ずつ base64 にして受け取ります(Windows PowerShell 5.1 は
2MB を超える JSON を読めないため)。
