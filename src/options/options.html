表示

製本表示・見開き・単ページ、綴じ方向、テーマ、表示位置。

開いたときの表示

表示中のPDFは、ツールバーの本のアイコンからいつでも切り替えられます。

綴じ方向

右綴じでは、← キーで次のページ、→ キーで前のページへ進みます(本をめくる向きと同じ)。

表示位置
テーマ
初期値 左に 90°

ツールバーの回転ボタンを押したときの動きです。ボタンを右クリックすると、向きと角度を選んで回転でき、「既定の設定を上書きする」でここを変えられます。Ctrl+[ ・ Ctrl+] はいつも 90° ずつです。

電子書籍・コミック

EPUB・MOBI・AZW・AZW3 の本は「電子書籍リーダー」で表示します(縦書き・右から左へめくる表示・目次・検索・PDF に保存)。 コミック(CBZ・CBR)と、画像だけでできた EPUB は、画像をそのまま並べた PDF にして製本ビューアで表示します(製本表示・印刷・PDF として保存が使えます。画質は元のまま)。 KFX と、DRM(コピー防止)がかかった本は表示できません。

コミックの読む向き

「本の情報」は、CBZ・CBR の ComicInfo.xml と、EPUB のページの進む向きです。表示しているときは、ツールバーの綴じ方向のボタンでも切り替えられます。

見開きの画像

画像は作り直さず、同じ画像の右半分・左半分を表示するページにします。製本表示で 2 ページが同じ見開きに並ぶよう、必要なら前に白紙のページを入れます。

パソコン内の本

「ファイルの URL へのアクセスを許可する」がオンのときに使えます(パソコン内の PDF と同じ)。

2スキャン・ページ操作

スキャンを整え、必要なページを取り出す・集める

スキャンの整え コピー・画像 ページ収集

スキャンの整え

見開きの分割、余白の除去、読む向き・1ページ目、PDF ごとの設定。

スキャンした見開き

本・ノートを開いてプリンター(コピー機)でスキャンした PDF を開くと、ノド(綴じ目)の位置で1ページずつに分けて表示します。 ばらした中綴じの冊子を両面スキャンした PDF は、ツールバーの「冊子を並べ替える」で、表紙から裏表紙の順に並べ替えられます。 画像は作り直さないので、画質は元のままです。元の PDF のファイルは変えません。

余白
本を読む向き

スキャンした見開きを分けるとき、どちらのページを先にするか(と、表示する見開きの並び)の初期値です。PDF ごとに「スキャンを整える」の画面で変えられ、変えたものは覚えておきます。

PDF の1ページ目
傾き

見開きを分けるときや冊子を並べ替えるときに、ページごとの傾き(約 0.2° 以上)も直します。 縦長のスキャン(1ページずつのスキャン)が傾いていれば、ツールバーの「傾きを直す」のボタンで知らせます(文字のある PDF は調べません)。 傾きは、画像を作り直さずに、ページの中身を回して直します(画質は元のまま)。

PDF ごとの整え方

PDF ごとに選んだ整え方(「元に戻す」を選んだことも含む)を覚えておき、次に開いたときも同じように表示します。

コピー・画像

右クリックの「コピー」、ショートカット、サムネイルを選んでのコピー、ページ収集の「PDF としてコピー」「画像としてコピー」の動きを決めます。

1ページのとき
複数ページのとき

サムネイルを Ctrl+クリックで複数選んでコピーしたときに使います。ファイルとしてクリップボードに入れるには、下の「補助プログラム」が必要です(無いときは、保存したファイルの場所をクリップボードに入れます)。

画像としてコピー(複数ページ)

1ページだけのときは、いつも画像そのものをクリップボードに入れます。

画像にする画質

dpi は、紙の 1 インチを何ピクセルで描くか(画像の細かさ)。ページの大きさからピクセル数が決まります。 元データ優先では、スキャンしたページは元の画像と同じ解像度で、劣化しない PNG にします。ファイルに保存するときは、ページが1枚の JPEG 画像だけでできていれば、 元の JPEG をそのまま取り出します(作り直さないので、画質も大きさも元と同じ)。画像が大きいと、コピー・保存に少し時間がかかります。 クリップボードに入れられなかったときは、自動で解像度を下げて再挑戦し、それでも駄目なら画像ファイルとして保存して知らせます。 PDF のコピー・保存は、画質の設定にかかわらず、いつも元の画質のままです(画像を作り直さず、OCR の文字も残ります)。

ショートカット

ビューアで押すと、マウスの下のページ(サムネイルを複数選んでいるときは選んだページ)をコピーします。Ctrl または Alt を含む組み合わせ、または F キーを登録できます。

補助プログラム
(ファイルのコピー)

確認中…

ブラウザの決まりで、拡張機能だけではファイル(PDF や画像のファイル)をクリップボードに入れられません。 「PDF としてコピー」などで、貼り付けたときにファイルとして貼り付くようにするには、拡張機能のフォルダの helper にある補助プログラムを入れてください。 補助プログラムは、製本ビューアから受け取ったファイルを見えない一時フォルダ(Windows では %TEMP%\seihon-viewer-copy)に置いて、クリップボードに入れるだけで、ほかの通信はしません。 「ダウンロード」フォルダには何も残らず、ダウンロードの一覧にも出ません。コピーは使い捨てで、次にコピーすると前のコピーのファイルは消えます。 補助プログラムが無いときは、「ダウンロード」の「製本ビューア_コピー」に保存して、ファイルの場所を文字でコピーします(このときも、次にコピーすると前のファイルは消えます)。

  1. 上の「補助プログラムを使えるようにする…」を押し、Chrome の確認で「許可」を押します(「ネイティブ アプリとの通信」の権限)。
  2. 拡張機能のフォルダの helper を開き、使っているパソコンのものを入れます。
    • Windows: helper\windows\install.bat をダブルクリック
    • Mac: helper/mac/install.command を右クリック →「開く」
    • Linux: 端末で sh helper/linux/install.sh(xclip または wl-clipboard が必要)
  3. 「もう一度確かめる」を押して「使えます」と出れば準備完了です。拡張機能のフォルダを移動したときは、もう一度入れ直してください。

補助プログラムが無いときは、保存したファイルの場所(パス)をクリップボードに入れます。ファイルを選ぶ画面の「ファイル名」の欄に貼り付けると、そのファイルを選べます。

3印刷・製本出力

紙に印刷する、製本用の PDF を作る

印刷の画質 製本用PDF出力 付属・ファイル名

印刷の画質

印刷の画質

元の PDF で印刷 では、Chrome の印刷画面で印刷します(ページを削除したり書き込んだりしていれば、その内容を反映した PDF を印刷します)。 印刷画面で「PDF に保存」を選ぶと、元の画質のまま、OCR の文字(スキャンした PDF の検索できる文字)も残った PDF になります。 画像として印刷・高画質・標準・自動では、ビューアがページを画像にしてから印刷します(「PDF に保存」すると文字も画像になります)。 ブラウザのメニューから印刷したときは、いつも画像にして印刷します(元の PDF で印刷 の設定のときは高画質)。

製本用PDF出力

ここで決めた内容は、製本用PDF出力の画面を開いたときの初期値になります(画面の「詳細設定」で、その回だけ変えることもできます)。

面付け

オフにすると、白紙を入れた読む順の PDF を出力します(並べ替えはプリンターの小冊子印刷に任せます)。

初期値 自動

自動では、元のページ2枚を横に並べて収まる用紙を選びます(A5 の本なら A4 横、B5 の本なら B4 横)。

両面の綴じ方向
白紙を入れる位置

本体(カバーの表紙+本文+カバーの裏表紙)のページ数が4の倍数になるよう、0〜3枚の白紙を入れます。

大きさの基準

ページの大きさがそろっていないとき、どのページの大きさに合わせて用紙を選び、ほかのページを拡大縮小するかを決めます。

出力ページのプレビュー

製本用PDF出力の画面の「出力ページのプレビューを表示しない」と同じです(画面で変えると、ここも変わります)。

付属・ファイル名

表紙や帯などの付属のページの扱いと、出力するファイルの名前。

付属の出力

付属は、表紙・裏表紙・帯・表紙の折り返し・裏表紙の折り返し・しおりの役割を付けたページです(カバーの表紙・裏表紙は本体に入ります)。

付属の役割の使い道
初期値 すべて「付属として出力」

付属の役割を付けたページを、製本用PDF出力でどう使うかを決めます。初期値では本体には入れず、付属の PDF(上の「付属の出力」)にまとめます。 たとえば、カバーではなく本の表紙を本の最初のページにしたい場合は、「表紙」を「最初のページ(カバーの表紙)の候補にする」にすると、 出力の画面の「カバーの表紙」の欄で候補として使われます。出力の画面で、その回だけ変えることもできます。

出力ファイル名
本体の PDF: 元の名前 +
付属の PDF: 元の名前 +

製本用PDF出力で作る PDF は、本体(本のページを読む順・面付けの順に並べたもの)と、付属(表紙・帯などの付属の役割のページだけを集めたもの)の2種類です。 本体はいつも作り、付属は、付属のページがあって「付属の出力」が「別の PDF にする」のときだけ作ります。 同じ名前のファイルがあるときは「名前 (1).pdf」のように別の名前で保存します(上書きしません)。

強制ダウンロード対策

対策

PDFと判断できるもの(ファイル名やURLが .pdf、または種類が PDF)に限って、ダウンロード指示を外して表示します。 PDFと判断できないものには触れません。POST の応答として返るPDFは対象外です。

1行に1サイト。ここに書いたサイトでは、サイトの指示どおりダウンロードさせます。

保存された元のファイル

それでもダウンロードが始まった場合(blob: の URL、ページのスクリプトによる保存など)、PDF なら保存されたファイルを製本ビューアで開きます(第3層)。 パソコン内のファイルを開くため「ファイルの URL へのアクセス」の許可が必要です。Alt+クリックなど自分で保存した PDF は開きません。

PDFページ数役割更新日時操作

ページ役割は、PDF の内容で見分けて PDF ごとに保存しています(同じ PDF を別の場所から開いても元に戻ります)。 消した役割は元に戻せません(下の「設定の書き出し」で書き出したファイルがあれば、読み込みで戻せます)。

書き出し

JSON 形式のファイル(製本ビューアの設定_日時.json)を、Chrome のダウンロード先のフォルダに保存します。 収集したページと元の PDF、速度ログは含めません。

    別のパソコンの Chrome や、入れ直した製本ビューアに、設定とページ役割を移すときに使います。読み込む前に、何が変わるかを確認できます。
