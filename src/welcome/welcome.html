試してみる

同梱のサンプル(12ページ)を製本表示で開きます。表紙(1ページ目)が右側に単独で、2ページ目以降が見開きで表示されれば正常です。

サンプルPDFを開く

使い方

PDFを開く

Webサイトや手元のPDFを開くと、自動で製本ビューアに切り替わります。ビューアにファイルをドラッグ&ドロップしても開けます。

製本表示

ツールバーの本のアイコンを押すたびに「単ページ → 製本表示 → 見開き」と切り替わります。その右のボタンで、綴じ方向(左綴じ・右綴じ)を切り替えます。

Chrome 標準で開く

ツールバー右側の「Chrome標準で開く」で、同じPDFを Chrome 標準のビューアで開きます。戻るときは拡張機能のアイコンを押します。

コピー

ページを右クリック →「コピー」(Ctrl+Shift+C)で、ページが元の画質の画像としてコピーされます。チャット欄や文書にそのまま貼り付けられます。

ページ収集

右クリック →「収集に追加」で、いろいろな PDF のページを溜めておけます。ツールバーの収集ボタンから、まとめて「PDF としてコピー」「画像としてコピー」したり、1つの PDF に保存したりできます。

製本用PDF出力

ツールバーの本と矢印のアイコンで、中綴じの本を印刷するための PDF(白紙の挿入・面付け)を作れます。カバー・表紙・帯などのページは、出力の画面の「カバー・表紙・帯などのページ」か、サイドバーの「選択」から指定します。

スキャンの整え

本・ノートを開いてプリンター(コピー機)でスキャンした見開きは、自動で1ページずつに分け、余白を除いて表示します。ばらした冊子を両面スキャンした PDF は、ツールバーの「冊子を並べ替える」で表紙から順に並べ替えられます。画質は元のままです。

電子書籍・コミック

EPUB・MOBI・AZW・AZW3 は電子書籍リーダーで表示します(縦書き・右から左へめくる・目次・検索・「PDF に保存」)。コミック(CBZ・CBR)と画像の EPUB は、画像をそのまま並べた PDF にして表示します。PDF は、ダウンロードボタンの「ほかの形式に変換して保存」で、画像(ZIP)・CBZ・EPUB・テキストにできます。KFX と DRM 付きの本は表示できません。

ページの削除と保存

☰ のサイドバーで、サムネイルの右上の ✕ でページを削除、「選択」でまとめて削除・役割の指定ができます。編集すると「保存」ボタンが出て、保存先を選んで新しい PDF として保存します(元のファイルは上書きしません)。

設定を移す

詳細設定の「設定の書き出し・読み込み」で、設定とページ役割をファイルに書き出し、別のパソコンや入れ直した製本ビューアに読み込めます。
