    Chrome の「PDF ドキュメント」の設定

    Chrome の設定で、PDF の扱いが「PDF をダウンロードする」になっていると、PDF がビューアで開かず保存されてしまいます。 「Chrome で PDF を開く」になっていることを確認してください(ここからは自動で確認できないため、目で確認をお願いします)。

文書と閲覧データの扱い

Web上のPDFを判別するため、ページのURLと応答の種類を確認します。文書を開き直す際には元のサイトに接続します。収集したページ、元の文書、閲覧位置はこの端末に保存します。

プライバシーポリシーを読む

試してみる

同梱のサンプル(12ページ)を製本表示で開きます。表紙(1ページ目)が右側に単独で、2ページ目以降が見開きで表示されれば正常です。

サンプルPDFを開く

使い方

PDFを開く

Webサイトや手元のPDFを開くと、自動で製本ビューアに切り替わります。ビューアにファイルをドラッグ&ドロップしても開けます。

製本表示

ツールバーの表示モードのアイコンを押し、「単ページ」「製本表示」「見開き」から選びます。その右のボタンで、綴じ方向(左綴じ・右綴じ)を切り替えます。幅が狭いときは「その他の操作」からも選べます。

Chrome 標準で開く

ツールバー右側の「Chrome標準で開く」で、同じPDFを Chrome 標準のビューアで開きます。戻るときは拡張機能のアイコンを押します。

コピー

ページを右クリック →「コピー」(Ctrl+Shift+C)で、ページが元の画質の画像としてコピーされます。チャット欄や文書にそのまま貼り付けられます。

ページ収集

右クリック →「収集に追加」で、いろいろな PDF のページを溜めておけます。ツールバーの収集ボタンから、まとめて「PDF としてコピー」「画像としてコピー」したり、1つの PDF に保存したりできます。

製本用PDF出力

詳細設定で「製本機能を使う」をオンにすると、「印刷・PDF保存」から製本用PDF出力へ進めます。ツールバーの「製本PDF」(中央に折り目のある用紙のアイコン)からも、中綴じの本を印刷するための PDF(白紙の挿入・面付け)を作れます。カバー・表紙・帯などのページは、出力の画面の「カバー・表紙・帯などのページ」か、サイドバーの「選択」から指定します。

スキャンの整え

補正は手動です。PDFを開いたときは元のまま表示し、勝手に検査や補正を始めません。必要なときに ⋮ メニューの「スキャンを整える…」を開くと、見開きの分割・余白や傾きの補正・冊子の並べ替えをプレビューで確認して適用できます。画質は元のままです。

電子書籍・コミック

EPUB・MOBI・AZW・AZW3 は電子書籍リーダーで表示します(縦書き・右から左へめくる・目次・検索・「印刷・PDF保存」)。コミック(CBZ・CBR)と画像の EPUB は、画像をそのまま並べた PDF にして表示します。PDF は、保存ボタンの「ほかの形式に変換して保存」で、画像(ZIP)・CBZ・EPUB・テキストにできます。KFX と DRM 付きの本は表示できません。

ページの削除と保存

☰ のサイドバーで、サムネイルの右上の ✕ でページを削除、「選択」でまとめて削除・役割の指定ができます。編集すると「保存」ボタンが出て、保存先を選んで新しい PDF として保存します(元のファイルは上書きしません)。

設定を移す

詳細設定で設定とページ役割をファイルに保存すると、別のパソコンや入れ直した製本ビューアに読み込めます。
