製本ビューア ― 同梱しているソフトウェアと素材のライセンス表記
====================================================================

この拡張機能には、次の第三者のソフトウェア・素材が含まれています。
それぞれの著作権は各権利者に帰属し、各ライセンスの条件に従って同梱しています。
ライセンスの全文は、表の「全文」に書いたファイルにあります(拡張機能のフォルダ内)。

--------------------------------------------------------------------
1. PDF.js
--------------------------------------------------------------------
  バージョン : 6.4.299(legacy ビルド、ビルド番号 d0991a0d5)
  入手元     : https://github.com/mozilla/pdf.js/releases/tag/v6.4.299
               (pdfjs-6.4.299-legacy-dist.zip)
  著作権     : Copyright 2012 Mozilla Foundation
  ライセンス : Apache License, Version 2.0
  全文       : pdfjs/LICENSE
  同梱範囲   : pdfjs/build/pdf.mjs, pdfjs/build/pdf.worker.mjs,
               pdfjs/web/viewer.mjs, pdfjs/web/viewer.css, pdfjs/web/images/
               (以上は配布物のまま無改変)
               pdfjs/web/locale/ は日本語(ja/viewer.ftl、無改変)のみを残し、
               locale.json を日本語だけの一覧に書き換えています。
               使わない部品(デバッグ用ファイル、ソースマップ、PDF 内の
               JavaScript を実行する部品 pdf.sandbox.mjs と QuickJS、
               日本語以外の翻訳、見本の PDF)は削除しています。
  変更       : viewer/viewer.html は PDF.js の web/viewer.html をもとに、
               ツールバー・サイドバー・検索バーを Chrome 風に組み替えたものです
               (Apache License 2.0 第4条に基づく変更の表示)。

  PDF.js の配布物には、さらに次の素材が含まれています。

  1-1. Adobe CMap(文字コード対応表)
       場所       : pdfjs/web/cmaps/
       著作権     : Copyright 1990-2009 Adobe Systems Incorporated.
       ライセンス : BSD 3-Clause License
       全文       : pdfjs/web/cmaps/LICENSE

  1-2. 標準14フォントの代替フォント(Foxit)
       場所       : pdfjs/web/standard_fonts/Foxit*.pfb
       著作権     : Copyright 2014 PDFium Authors
       ライセンス : BSD 3-Clause License
       全文       : pdfjs/web/standard_fonts/LICENSE_FOXIT

  1-3. Liberation フォント
       場所       : pdfjs/web/standard_fonts/Liberation*.ttf
       著作権     : Copyright 2007-2011 Red Hat, Inc.
       ライセンス : GNU General Public License v2(フォント例外条項付き)
       全文       : pdfjs/web/standard_fonts/LICENSE_LIBERATION
       備考       : フォントは無改変で同梱しています。PDF の表示に使うだけで、
                    表示・保存した文書が GPL の対象になることはありません
                    (ライセンスの例外条項 (a))。

  1-4. OpenJPEG(JPEG 2000 画像の展開、WebAssembly)
       場所       : pdfjs/web/wasm/openjpeg.wasm, openjpeg_nowasm_fallback.js
       ライセンス : BSD 2-Clause License(OpenJPEG 本体と Mozilla の組み込み部分)

  1-5. JBIG2 デコーダ(PDFium 由来、WebAssembly)
