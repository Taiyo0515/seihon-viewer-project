表示

開いたときの表示

表示中のPDFは、ツールバーの本のアイコンからいつでも切り替えられます。

綴じ方向

右綴じでは、← キーで次のページ、→ キーで前のページへ進みます(本をめくる向きと同じ)。

表示位置
テーマ
印刷の画質

最高画質では、Chrome の印刷画面で印刷します(ページを削除したり書き込んだりしていれば、その内容を反映した PDF を印刷します)。 印刷画面で「PDF に保存」を選ぶと、元の画質のまま、OCR の文字(スキャンした PDF の検索できる文字)も残った PDF になります。 高画質・標準・自動では、ビューアがページを画像にしてから印刷します(「PDF に保存」すると文字も画像になります)。 ブラウザのメニューから印刷したときは、いつも画像にして印刷します(最高画質の設定のときは高画質)。

スキャンの整え

スキャンした見開き

本・ノートを開いてプリンター(コピー機)でスキャンした PDF を開くと、ノド(綴じ目)の位置で1ページずつに分けて表示します。 ばらした中綴じの冊子を両面スキャンした PDF は、ツールバーの「冊子を並べ替える」で、表紙から裏表紙の順に並べ替えられます。 画像は作り直さないので、画質は元のままです。元の PDF のファイルは変えません。

余白
PDF ごとの整え方

PDF ごとに選んだ整え方(「元に戻す」を選んだことも含む)を覚えておき、次に開いたときも同じように表示します。

コピー・画像

右クリックの「コピー」、ショートカット、サムネイルを選んでのコピー、ページ収集の「PDF としてコピー」「画像としてコピー」の動きを決めます。

1ページのとき
複数ページのとき

サムネイルを Ctrl+クリックで複数選んでコピーしたときに使います。ファイルとしてクリップボードに入れるには、下の「補助プログラム」が必要です(無いときは、保存したファイルの場所をクリップボードに入れます)。

画像としてコピー(複数ページ)

1ページだけのときは、いつも画像そのものをクリップボードに入れます。

画像の画質

最高画質では、スキャンしたページは元の画像と同じ解像度で、劣化しない PNG にします。ファイルに保存するときは、ページが1枚の JPEG 画像だけでできていれば、 元の JPEG をそのまま取り出します(作り直さないので、画質も大きさも元と同じ)。画像が大きいと、コピー・保存に少し時間がかかります。 クリップボードに入れられなかったときは、自動で解像度を下げて再挑戦し、それでも駄目なら画像ファイルとして保存して知らせます。 PDF のコピー・保存は、画質の設定にかかわらず、いつも元の画質のままです(画像を作り直さず、OCR の文字も残ります)。

ショートカット

ビューアで押すと、マウスの下のページ(サムネイルを複数選んでいるときは選んだページ)をコピーします。Ctrl または Alt を含む組み合わせ、または F キーを登録できます。

補助プログラム
(ファイルのコピー)

確認中…

ブラウザの決まりで、拡張機能だけではファイル(PDF や画像のファイル)をクリップボードに入れられません。 「PDF としてコピー」などで、貼り付けたときにファイルとして貼り付くようにするには、拡張機能のフォルダの helper にある補助プログラムを入れてください。 補助プログラムは、製本ビューアから受け取ったファイルを「ダウンロード」フォルダの「製本ビューア_コピー」に保存して、クリップボードに入れるだけで、ほかの通信はしません (Chrome の「保存する前に各ファイルの保存場所を確認する」がオンでも、聞かれずに裏で保存します)。

  1. 上の「補助プログラムを使えるようにする…」を押し、Chrome の確認で「許可」を押します(「ネイティブ アプリとの通信」の権限)。
  2. 拡張機能のフォルダの helper を開き、使っているパソコンのものを入れます。
    • Windows: helper\windows\install.bat をダブルクリック
    • Mac: helper/mac/install.command を右クリック →「開く」
    • Linux: 端末で sh helper/linux/install.sh(xclip または wl-clipboard が必要)
  3. 「もう一度確かめる」を押して「使えます」と出れば準備完了です。拡張機能のフォルダを移動したときは、もう一度入れ直してください。

補助プログラムが無いときは、保存したファイルの場所(パス)をクリップボードに入れます。ファイルを選ぶ画面の「ファイル名」の欄に貼り付けると、そのファイルを選べます。

製本用PDF出力

ここで決めた内容は、製本用PDF出力の画面を開いたときの初期値になります(画面の「詳細設定」で、その回だけ変えることもできます)。

白紙を入れる位置

本体(カバーの表紙+本文+カバーの裏表紙)のページ数が4の倍数になるよう、0〜3枚の白紙を入れます。

面付け

オフにすると、白紙を入れた読む順の PDF を出力します(並べ替えはプリンターの小冊子印刷に任せます)。

初期値 自動

自動では、元のページ2枚を横に並べて収まる用紙を選びます(A5 の本なら A4 横、B5 の本なら B4 横)。

両面の綴じ方向
大きさがそろっていないとき
付属の出力

付属は、表紙・裏表紙・帯・表紙の折り返し・裏表紙の折り返し・しおりの役割を付けたページです(カバーの表紙・裏表紙は本体に入ります)。

付属の役割の使い道
初期値 すべて「付属として出力」

付属の役割を付けたページを、製本用PDF出力でどう使うかを決めます。初期値では本体には入れず、付属の PDF(上の「付属の出力」)にまとめます。 たとえば、カバーではなく本の表紙を本の最初のページにしたい場合は、「表紙」を「最初のページ(カバーの表紙)の候補にする」にすると、 出力の画面の「カバーの表紙」の欄で候補として使われます。出力の画面で、その回だけ変えることもできます。

出力ファイル名
元名.pdf / 元名_面付け.pdf
元名.pdf(付属)

同じ名前のファイルがあるときは「名前 (1).pdf」のように別の名前で保存します(上書きしません)。

強制ダウンロード対策

対策

PDFと判断できるもの(ファイル名やURLが .pdf、または種類が PDF)に限って、ダウンロード指示を外して表示します。 PDFと判断できないものには触れません。POST の応答として返るPDFは対象外です。

1行に1サイト。ここに書いたサイトでは、サイトの指示どおりダウンロードさせます。

保存された元のファイル

それでもダウンロードが始まった場合(blob: の URL、ページのスクリプトによる保存など)、PDF なら保存されたファイルを製本ビューアで開きます(第3層)。 パソコン内のファイルを開くため「ファイルの URL へのアクセス」の許可が必要です。Alt+クリックなど自分で保存した PDF は開きません。

PDFページ数役割更新日時操作

ページ役割は、PDF の内容で見分けて PDF ごとに保存しています(同じ PDF を別の場所から開いても元に戻ります)。 消した役割は元に戻せません(下の「設定の書き出し」で書き出したファイルがあれば、読み込みで戻せます)。

設定の書き出し・読み込み

書き出し

JSON 形式のファイル(製本ビューアの設定_日時.json)を、Chrome のダウンロード先のフォルダに保存します。 収集したページと元の PDF、速度ログは含めません。

読み込み

    別のパソコンの Chrome や、入れ直した製本ビューアに、設定とページ役割を移すときに使います。読み込む前に、何が変わるかを確認できます。
